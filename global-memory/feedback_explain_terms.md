correction: 2026-09-05. "cursor.com is blocked by the egress proxy" went out with no account of what the proxy was, that the session ran in a cloud sandbox, or that a network policy the user controls decided it. Every first mention of a tool, service, or environment component carries one sentence: what it is, where it runs, what it means for the user right now. The user's words: "you're doing that thing where you're throwing around phrases without providing any context."
